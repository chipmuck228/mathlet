# Mathlet

Mathlet 是用于中考数学复习小册子的本地编辑与审核工作台。学生最终拿到可留存的读物；工作台服务于资料整理、数学内容研究、教师审核与版本交付。

**当前为 0.3 本地版：新增阶段0方法与数据契约、阶段1知识草案 Agent 和教师审核。** 资料导入、原题核对和既有提纲无需密钥；知识草案需要配置实际模型服务并显式触发，不自动发送原件。已支持核查意见分类、定向补充／修订／拆分、当前批次完整性建议及关系候选审阅；新增“题目与研究”：多版本知识关联、完整题目与答案状态核对、分类／知识分解／解题思路候选、独立复核及教师审核固定。新增“整卷研究”：核对文件→自动分题建议→知识终稿推荐→批量单题研究→跨题思路卡，教师逐步修订与定稿。全册自动图谱、视觉理解及整本小册子生成尚未接入。

## 本地运行

需要 Git、Python 3.11+、Node.js 22.12+（建议使用仍受支持的 LTS）。DOCX 原页预览另需本机安装 LibreOffice；找不到 soffice 时可设置 `MATHLET_SOFFICE` 为可执行文件绝对路径。未安装时仍可提取和编辑，但右侧会提示无法生成原页。自动转换会读取已保存的 LibreOffice 字体／语言设置后在独立配置中运行；手动设置过字体替换后请先退出 LibreOffice，再重新生成预览。macOS/Linux：

```bash
git clone https://github.com/chipmuck228/mathlet.git
cd mathlet
python3 scripts/setup.py
python3 scripts/dev.py
```

浏览器打开 **http://127.0.0.1:5173**。`Ctrl+C` 停止前端、API 与 Worker。

Windows 可将上述 `python3` 替换为 `py`。启动脚本包含 Windows 分支，但本轮只在 Linux 验证，macOS/Windows 仍需本机验收。

已有仓库更新：

```bash
git pull --ff-only
python3 scripts/setup.py
python3 scripts/dev.py
```

`setup.py` 建立项目内 `.venv`，安装 Python 依赖并执行 `npm ci`。第一次安装需要网络。不要把代理或密钥写进仓库。

## 知识草案试点（新增）

左侧进入“知识与关系”：配置模型 → 保存单元范围 → 生成清单 → 选择展开 → 校正与批量确定范围 → 教师确认 → 固定知识版本。无需先上传教材正文。详见[使用说明](docs/KNOWLEDGE_DRAFTS.md)、[方法论](docs/METHODOLOGY.md)、[数据与审核契约](docs/KNOWLEDGE_CONTRACT.md)。默认试点“一元二次方程—二次函数”，对照“一元一次方程”。模型运行不代表数学已审核，教师范围选择不代表官方课标覆盖。

## 第一轮使用

新增流程：上传课标摘要等资料后，可进入 **内容规划 → AI 构建领域与二级主题 → 核对编辑与定稿 → 按主题生成知识**；教材编号规则导入继续保留。详见[内容规划使用流程](docs/CONTENT_PLANNING.md)。目录结构确认不代替来源核对，也不代表全册课标覆盖完成。旧数据升级自动增加规划表，不清空原有资料。

1. **资料包**：上传 DOCX 或 PDF，选择资料类别。文件保存在本机，Worker 执行实际读取。
2. **原题核对**：AI先整理标题、完整题目和原文解答，教师按题审阅、编辑公式、从全部图片替换配图，整卷统一定稿为只读提取文件；右侧保留原文预览与下载。详见[整份试卷提取流程](docs/EXAM_EXTRACTION.md)。课标／教材和旧核对记录保留兼容。
3. **任务与生成**：从当前资料中选取已确认内容，创建小册子单元的编辑提纲。此步骤不会生成数学解答。
4. **编辑与评审**：填写讲解、知识连接、可行思路、独立训练及答案。填写审核人并保存批注；每次正文保存产生新修订并撤销旧批准。
5. **小册子预览**：打开已保存内容的阅读版，用浏览器打印功能另存 PDF。当前是简单排版，尚非专业分页出版版。
6. **交付版本**：批准当前修订后创建不可变快照，下载含图像的离线 HTML。后续编辑不改变已保存版本。

DOCX 按段落／表格分块，PDF 按页分块。保存原题核对结果后，进入 **整卷研究**，由 AI 提出分题边界与知识推荐，再批量研究；教师检查题干、续页、图表、答案之间的对应。详见[整卷研究与思路卡](docs/PAPER_RESEARCH.md)。

新增[公式核对与编辑](docs/FORMULA_REVIEW.md)：新上传 DOCX 保留常见原生公式结构，可点击公式进行可视化修改；已有资料可“重新提取公式候选”后人工采用，不覆盖历史修订。PDF／图片公式暂不自动识别，可手工插入公式。

你提供的模拟试卷不随代码分发。请在本机上传原文件。不要把原始试卷放进 Git 目录的可跟踪路径。

## 已实现与边界

| 能力 | 当前状态 |
| --- | --- |
| DOCX/PDF 上传与原件下载 | 已实现，单份最多30MB，PDF最多120页 |
| DOCX 文本、部分原生公式、可解码图片、表格 | 已实现结构化公式转换与编辑；不支持的结构明确提示 |
| PDF 文本提取与页面图 | 已实现；不保证文字顺序或公式结构 |
| 原始文档页面预览 | PDF 直接显示原件；DOCX 通过本机 LibreOffice 转换，失败可重试 |
| 自动分题、知识推荐、整卷研究、跨题思路卡 | 已实现 AI 建议、来源定位、教师修订和固定终稿；不自动批准 |
| 扫描件 OCR、与 Word 完全一致的排版 | 未实现；需人工对照和补录 |
| 持久化任务、失败重试、Worker重启恢复 | 已实现；本地单 Worker |
| 来源核对、编辑、批注、明确批准 | 已实现，带修订号冲突检查 |
| 来源变更使下游批准失效 | 已实现；不自动重写下游正文 |
| 内容规划与目录树 | 已实现AI构建来源绑定的领域／二级主题／学习要求、人工编辑定稿；保留编号规则识别 |
| 小册子单元规划与课标对应 | AI提出要求对应、人工核对；定稿主题携带来源要求进入知识生成，不宣称覆盖完整 |
| 交付快照、离线 HTML、浏览器打印 | 已实现 |
| 完整修订差异视图、来源图上的框选定位 | 未实现 |
| 知识清单、知识草案、模型疑问、教师范围审核与知识快照 | 已实现，需配置真实模型服务；不把模型输出当成已审核知识 |
| 多版本关联与完整题目研究 | 已实现版本绑定、跨块题目核对、解题思路候选、独立一轮复核、教师审核及不可变研究JSON；自动分题和图像理解未实现 |
| 动画、视频、二维码发布、互联网发布 | 未实现 |
| 登录、多用户权限、远程访问 | 未实现，仅本机使用 |

概念、性质和论证必须正确；示例路径可以多样。软件中的“已批准”记录人的确认，不代表程序证明了数学正确性。第一版允许编辑者批准内容，不提供教师资质验证或双人审批。

## 数据保存与备份

默认数据目录是仓库根目录 `data/`：

- `mathlet.sqlite3`：资料、任务、核对状态、草稿、批注和版本快照。
- `documents/<id>/original.*`：原始文件。
- `documents/<id>/assets/`：提取图片或 PDF 页面图。

可通过启动环境变量 `MATHLET_DATA_DIR` 指定**绝对路径**。API 和 Worker 必须使用同一目录。项目暂不自动读取 `.env`。

**GitHub 只同步代码、设计、模板与测试，不备份工作数据。** `.gitignore` 排除资料、数据库和环境密钥。备份时先停止三个服务，再复制完整数据目录；恢复时保留原有目录结构。不要只复制运行中的 SQLite 主文件，也不要用 Git 同步两台机器正在使用的数据库。

服务默认只监听 `127.0.0.1`，本版没有账户与权限系统。请勿改为公网或局域网服务。本地应用仍需对来源不明的大文件保持谨慎；解析尚未放入资源受限的隔离进程。

## 开发与测试

```bash
npm run build
npm test
.venv/bin/python -m pytest apps/api/tests -q
```

Windows 的 Python 路径为 `.venv\Scripts\python.exe`。

分开运行时，在根目录开启三个终端：

```bash
.venv/bin/python -m uvicorn mathlet.main:app --host 127.0.0.1 --port 8000
.venv/bin/python -m mathlet.worker
npm run dev
```

API 文档：http://127.0.0.1:8000/docs 。已有前端构建时，也可以通过 http://127.0.0.1:8000 使用工作台；仍需单独启动 Worker。

## 小节基础内容编制

内容规划支持同页完成领域与小节规划、知识清单选择、正文编辑、关系核对与小节整体定稿。AI 规划区域可折叠，取消新建传统教材目录导入入口，旧数据保留。打开小节恢复历史，不会自动重新生成；清单经教师选择才展开正文，关系经审定与正文一起固定。详见[小节基础内容工作流](docs/SECTION_FOUNDATIONS.md)。

## 小节应用与训练

“任务与生成”新增从知识终稿与完整题目生成应用映射、五阶段思路训练及完整解析的闭环。教师修订、审定后可下载含公式、配图和知识回链的离线HTML读物，并通过浏览器打印PDF。可直接选择本机已定稿的“二元一次方程组”10项知识与代表题；没有内置替代用户材料的虚构终稿。详见[实际运行步骤与验证边界](docs/TEACHING_LOOP.md)。

## 整份原题提取与核对

真题核对不再要求逐块确认：AI定位原文→整题编辑与图片选择→整卷审定→固定原题提取JSON。提取终稿可直接进入题目研究、训练闭环或整卷研究，保留原文和旧版本。原文答案的转录核对不等于数学正确性验证。详见[操作与边界](docs/EXAM_EXTRACTION.md)。
