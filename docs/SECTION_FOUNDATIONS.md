# 同页编制小节基础内容

“内容规划”现在承担领域—小节—基础内容的连续工作流。AI 规划区域使用折叠面板；取消新建传统“导入教材目录”的页面入口，旧规划及 API 保留。

## 操作

1. 展开“用 AI 构建领域与二级主题”，从导入资料生成分类候选。核对领域、小节及来源学习要求，保存并确认规划。
2. 在“2 主题目标与知识生成”中选择小节、核对目标，点击“打开本小节基础内容”。工作区出现在同一页面下方，不跳转到另一个导航页面；该操作创建或恢复此规划修订对应的知识单元，不调用模型。
3. 新小节点击“生成本小节知识清单”。AI 只起草清单，不自动展开；教师核查并勾选要纳入的条目后点击“生成选中知识正文”。定义、概念和术语归入概念类，性质、定理、方法分别组织；公式、成立条件、正例、反例与掌握表现在正文展开。数量上限不等于完整性保证。
4. 在三栏工作区阅读、编辑正文或请 AI 讨论和补充。适用范围仍由教师决定，可批量设置仍待定的条目，个别条目单独调整。保存条目只是保存工作稿。
5. 正文检查后进入关系核对，点击“生成知识关系”。每条关系的端点、类型、依据、条件、例子都可修改，可移出或补充。AI 初始返回不被人工编辑覆盖，教师修改在小节定稿时一起提交；尚未定稿的关系修改会阻止切换离开并触发未保存提示。需要先修改正文时，可取消本轮关系修改后返回正文。
6. 教师明确审定知识正文、适用范围及知识关系，点击“定稿本小节基础内容”。固定知识版本包含经教师确认的关系、原 AI 关系记录 ID 和正文，后续单题研究可以直接引用。空关系列表也可以明确确认，表示本轮没有需要纳入的关系，不表示已经穷尽连接。
7. 终稿只读。继续修订创建新工作稿，旧终稿不变；修改正文、范围、排序或纳入条目后，旧关系上下文不再适用，需要基于当前正文重新生成并核对。

## 旧数据

打开已有稿件不会重新调用模型。以前只有知识正文的终稿显示“知识已定稿，关系待补全”；可基于其继续修订、补关系后形成新的小节终稿。独立“知识与关系”入口暂保留，兼容既有独立知识稿；该旧入口仍允许只定稿正文，未经人工确认的 AI 关系不会悄悄变成已审定内容。

原文或规划范围变化时沿用现有过期校验，不将旧稿自动挂到新范围。未保存的知识／关系修改时禁止切换规划、小节及主要标签。AI 调用、检查点、失败重试沿用现有记录；小节清单、正文、关系分别明确触发，不静默反复调用模型。

本轮未引入新数据库表。小节终稿仍是 knowledge_versions；其中 editorial.relations_teacher_confirmed 区分是否连同关系整体审定，relations 保存已审关系。接口必须验证关系来自本稿当前修订的完成记录、端点属于纳入知识且不重复/自指，人工修改不覆盖 AI 原返回。独立旧版终稿的读取和数学内容研究保持兼容。

真题分题、知识匹配、单题研究与思路卡继续使用现有“整卷研究”和“题目与研究”，未自动并入本次基础内容编制，也不将知识关联当成唯一解法或课标完整性证明。
