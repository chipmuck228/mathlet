# Mathlet 产品与教学设计

Mathlet 帮助编辑团队把可信资料转化为经过审核的中考数学复习读物。使用者是编辑、数学教师；学生阅读小册子与必要的视觉材料。它不以刷题量、押题或固定解法为目标。

详细方法与阶段0约定见 METHODOLOGY.md，阶段1流程见 KNOWLEDGE_DRAFTS.md。知识整理由AI起草、教师校正选择；不要求先人工录入教材正文。

## 学习范围与学生

面向已学过初中三年内容、基础程度不同的学生。首先补齐基础概念和基本应用，再训练在新情境下建立关系与选择方法。不承诺分数；通过学生能否独立解释依据和迁移判断学习效果。正式全册需建立逐条课标覆盖表，试卷频率不能替代覆盖要求。

## 内容组织

拟分为数与代数、函数与图像、图形与几何、统计概率与实际问题、知识连接、综合运用六部分。基础单元包含概念、性质及条件、正反例、知识连接、完整示例、关键步骤训练、独立迁移和核对。综合实践内容穿插，不仅放在最后。

知识连接围绕共同对象展开：条件分别施加什么约束，哪条性质允许转译，目标需要何种结果，何处需要分类和检验。分类是探索入口，不是强制算法。一题可有多个合理标签、解法和关系路径。

例如反比例函数与矩形面积问题：边的位置确定坐标形式，同一反比例函数提供 xy=k，面积分割形成目标量，配方与变量范围决定最值。教师应检查每一连接依据，不仅核对最后一个数。

## 证据与审核

原件不变，提取结果与人工修正分别保存。DOCX 公式按结构转换，复杂公式需原件核对；PDF 页面是读取依据，文字层不能代替图形。不得从示意图比例推断未标注的垂直、平行和等长。

两道审核独立：原题是否准确、数学讲解是否有效。教师可修正文稿或提出意见。修改不能继承旧批准。教师也可能出错，后续要有独立求解、边界检查、学生试读和勘误。

## 本地版交付

0.1 支持文件导入、人工确认、提纲编写、单元编辑与批注、审核、离线 HTML 快照与浏览器打印。尚未提供模型写作和专业 PDF 排版。工作台的“交付版本”是本地版本固定，不是互联网公开发布。

未来动画采用精确图形与参数关系生成，视频以审核后的脚本驱动。纸面核心讲解必须完整，扫码材料用于预测、观察和解释，不替代论证。

## 试点

先用函数与图像构建完整单元，选取函数与方程、函数与几何的真实材料。教师审核后组织不同基础学生试读，观察他们是否能解释为什么联立、为什么分类、为什么检查范围。验证有效后扩大题库和全册生成。
