# Mathlet 方法论与阶段约定

状态：阶段0约定已落地；阶段1知识草案生产与审核已实现；阶段1定向完善和阶段2当前批次关系候选已实现；多个已审版本之间的关联候选、完整题目组装、知识分解与多路径研究、独立一轮复核和教师审核版本已实现；自动归并、全册整合及出版仍为计划。

## 学生目标与生产目标

学生交付物是可下载、可留存的数学复习读物，辅以必要的网页演示，不是要求学生操作的知识图谱软件。不以押题、刷题数量或唯一标准路径组织内容，也不承诺考试分数。

教学主线：基础知识 → 共同对象与知识连接 → 条件和目标分解 → 路径选择及逐步推理 → 迁移训练 → 检查反思。知识准确性与教学有效性都需要核查，数学教师及模型均可能出错。

## 起草与审核的分工

编辑只需提供章节或单元、目标学生和补充说明，即可启动知识清单起草。教材正文和完整课标不是启动前提。不要求教师先手工建好知识库。只有目录时也不把目录当作数学定义、性质或完整性证据。

先生成清单，由编辑选择要展开的知识，再分批生成准确表述、成立条件、公式、正例、易错点或反例、掌握表现、方法步骤及不确定问题。系统进行结构、公式可渲染性与缺项检查，并单独调用一轮模型提出数学疑问；不是数学证明或独立专家认证。

教师以修改、补充、退回和选定范围为主。支持按组保存适用范围、确认已检查的条目，而非逐字段审批。人工修订不能由Agent重跑覆盖。后续只需比较修改及其影响，不重复审核完全相同的基础知识。

## 三种判断彼此独立

1. 内容正确性：定义、性质、公式和条件是否成立，正反例是否有效。
2. 课程适用性：基础必备、连接与综合、拓展选读、不纳入；未决定时为待确定范围。
3. 依据状态：模型已有知识起草、教师补充、未来的真实来源引用。当前没有教材检索，不生成假的课标编号、页码或出处。

教师确认表示记录了审核人的判断，不表示程序已经证明知识正确。未逐条核验课标时，称为教师确认的复习范围，不宣称官方课标完整覆盖。

掌握表现描述学生能做出什么可观察行为；来源依据说明知识或关系来自哪里，不能将两者都塞入一个含混的 evidence 字段。

## 题目与范围（后续阶段）

真题原稿以题设有效为正常前提；核对重点是提取是否忠实、题目是否完整、图题是否对应。发现矛盾时提出问题，不自行改题或从图形观感补条件。

难度高不等于超范围。题内新定义、难的基础知识组合、超范围解法以及尚未找到范围内解法是不同情况。原始参考答案、AI推导答案和教师修订答案分别保存；未核对答案不阻止研究已完整核对的题目。

## 知识、关系和路径（后续阶段）

概念、性质、定理、方法分别表达。关系区分类别、属性、前置、表示转化、方法应用和题目考察；都应能解释理由、条件及依据。前置需要区分必要与辅助，教材顺序或名称相近不能证明依赖。

只对明确要求无环的关系检查循环。相关联系、可逆转化及不同解题路径可以成环。一次结构校验通过不能证明关系正确。

单题可有多条路径，按各步骤的条件、依据、推理、分类和检验展开。分类是探索入口，不是强制解法。教学编排围绕“基础→连接→思考→独立练习”，按实际需要加入精确动画；动画观察不代替论证。

## 可追溯与发布

稳定ID不以教材章号为依据。阶段1在同一知识清单及其衍生候选中保留知识ID；独立清单之间不自动合并同名知识，跨批次语义整合属于阶段2。

模型运行与人工审核分开。未完成、过期或有待处理疑问的知识不能被暗中当作已审核内容。编辑改变条目后撤销该条目的确认；改变生成范围后旧候选保留供参考，禁止当前确认。固定知识版本为不可变快照，后续修改不改写旧文件。

当前知识版本不是学生读物或互联网发布。后续题目研究、单元编排及资源发布还需分别固定其依赖版本并审核。
