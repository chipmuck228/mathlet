# 内容规划使用流程

“内容规划”提供两种入口：AI 从导入资料构建“领域—二级主题—学习要求”的待审核规划；传统规则按教材编号识别目录。AI 模式需要模型配置和明确发送确认，规则模式不调用模型。两者都不自动证明知识体系完整。

## AI 构建领域与二级主题

1. 在资料包上传课标摘要、教材目录或知识资料（DOCX/PDF），等待读取完成。在“知识与关系”保存模型配置。
2. 打开“内容规划”顶部“用 AI 构建领域与二级主题”，选择资料。展开“本次将发送的提取正文”对照范围，必要时刷新；不是发送原始文件字节或图片。
3. 可留空分类要求，或写“按领域归类主要内容，保留学习程度要求”。设置主题上限，确认发送，点击“AI 构建待审核规划”。模型实际提出分类，不固定套用九类模板，也不依赖“第几章”。
4. 任务完成后点击“打开生成规划进行核对”。每次生成新规划，不覆盖旧规划或编辑。失败与中断只能显式重试，查看调用记录及原始返回；来源变化后须新建任务。
5. 在“领域与二级主题”核对来源引文、编辑名称和主题归属、增补领域和主题、调整同级顺序或选择不纳入。每个二级主题自动关联一个知识生成单元；名称与所属领域同步维护。点击主题可编辑学习目标对应建议、勾选相关来源要求。
6. 在“来源学习要求”核对逐字摘录及其承接主题，保留导入资料中的原始要求和AI目标对应建议的区别。不把课标摘要自动标成已核验教育部原文。来源文字需修正时进入对应来源块；修改原文会使旧规划过期。
7. 保存修改，在“核对与确认”填写确认人并明确确认分类、主题、引文与目标对应。来源摘要尚未在原题核对中批准，不会伪装成已核验课标；结构定稿也不等于数学正文审核。
8. 在“主题目标与知识生成”选择主题，点击“按此主题进入知识生成”。自动带入名称、领域、来源学习要求、可编辑目标建议和规划修订号。也可从“知识与关系”的已确认规划选择主题。

后续知识清单及正文生成会收到来源学习要求；核查、扩展、修订、拆分、完整性建议与关系审核均保留。重复带入同一规划主题和修订只打开已有知识单元，不覆盖其人工修改。规划修订或原文变化使关联知识及未完成任务过期；原知识和旧发布文件保留。

一个任务发送一个资料的全部提取正文，最多200块、90000字符，输出预留8000 tokens，主题上限默认80、可设1—120；上限不表示覆盖完整。超限资料须拆分，不静默截断。扫描页无文字需先OCR或补录。模型返回截断／无效结构时保留失败证据，不建立部分规划；请按实际资料范围缩小文件或主题上限后重建。

模型领域、主题和要求必须引用有效来源块及其中的连续原文；要求对应必须引用本领域已有要求代号。没有学习要求的资料可以返回空要求，但会保留不足提示。未被模型引用的来源块提示核查，不能据引用数量判断学习内容完整性。

AI任务复用单Worker、模型配置快照、预算、调用记录、失败重试和中断恢复；内部调度单元不显示在知识单元列表。无需新依赖或重建本地数据。

## 本地更新

先停止旧服务，再在仓库根目录运行：

```bash
git pull --ff-only
python3 scripts/setup.py
python3 scripts/dev.py
```

打开 http://127.0.0.1:5173 。已有资料、草稿和交付数据会保留；启动时只增加规划相关表及迁移记录，不删除或重建旧表。升级前仍建议在停服状态备份完整 data 目录。

## 传统规则模式：用六册教材目录试运行

1. 在“资料包”选择“教材／知识资料”，上传目录 DOCX。等任务完成，资料状态变为待核对。
2. 进入“内容规划”，选中目录资料，点击“识别目录树”。识别过程依据标题与编号，不是模型推断。每次导入建立一个独立规划，不覆盖旧规划。
3. 在“教材章节树”展开册次和章，检查标题、类型与上级关系。点击条目编辑；可补充人工下级条目，可不纳入某个条目，但不自动排除其下级。导入条目的来源保持绑定，不自动合并相同章号。
4. 点击“查看对应来源块”，可跳到原题核对页的准确位置。需要保留规划修改时先保存。原件下载和教材网页链接分别保留；本工具不自动抓取网页正文。
5. 进入“小册子单元”，增加“基础复习”“跨章连接”或“综合训练”。填写所属分册、标题、学习目标，并关联一项或多项目录。比如“函数与平行四边形”同时关联函数、坐标和平行四边形相关条目。可用上移调整单元顺序。
6. 进入“核对与确认”，查看重复章号、概率关键词缺失及未识别行。未识别行可能是说明文字，也可能是真正漏项，可查看各行来源。记录人工判断后保存，再填写确认人并勾选声明，确认当前规划。

用户提供的示例目录实测识别为6个册次、239个链接目录条目，合计245个树节点。九年级下册与九年级上册重复的章号被保留并提示，没有重编号。这不代表目录内容和版本已经核实。

## 建立课标对应

1. 另行上传真实课标／考纲，上传类别选择“课标／考纲”。
2. 在“原题核对”中修正并确认相关来源块。
3. 回到“内容规划”的“课标对应”，选择该资料与已确认块，逐字摘录一条要求。可摘录原文的一部分，不能写入来源不存在的自拟要求。
4. 将要求关联到一个或多个小册子单元，保存规划。

“已安排单元”仅说明存在计划对应，不表示单元正文已满足要求。尚未录入完整课标时不能计算全册覆盖率，界面不会显示100%覆盖或已掌握。

## 从规划进入编辑

规划确认后，先在“原题核对”中确认所关联的具体来源条目，再回到单元点击“进入编辑提纲”。标题、目标与知识关联会带入已有编辑流程；提纲不含自动生成的数学解答。

同一规划单元重复点击只打开原稿，不重新生成或覆盖。后续调整规划，会撤销关联草稿的旧批准；提纲正文仍需人工同步。界面明确显示该限制，不能把旧文稿当作自动同步后的结果。

## 修改与过期

保存规划后递增修订并撤销结构确认；所有关联草稿撤销旧批准。来源原文发生修改，或关联课标被取消核对时，规划标记为过期，无法确认或建立新稿。仅将目录来源从未核对改为已核对、且原文不变，不会使结构规划过期；这保证先确认目录、再核对条目的流程可以继续。原文更改后，当前处理方式是重新导入新规划，旧规划保留供人工参考，不自动迁移或拼接旧修改。

同时打开两个编辑页面时，旧页面的保存或确认会被409拒绝。请先复制未保存内容，再重新载入；不要反复提交覆盖。已固定交付的快照保持不变。

## 已知边界

- 识别依赖分行标题。PDF 中的多列、扫描页或一段包含多个标题时，需要先补录或整理；普通试卷不会被猜成章节树。
- 目录年份、出版社版次不会由网页路径推断。章节编号只作为来源标签，不能作为跨版本统一知识 ID。
- 当前跨章关联仅在同一导入规划内部；多份目录树合并、语义同义项匹配、课标完整性审查、与题库自动关联仍未实现。
- 规划尚无完整历史差异、删除、自动分册建议和自动内容生成。
- 树确认与数学内容审核是两件事，确认目录不代替概念、性质、题目与答案审核。
