# 小节知识—真题应用—思路训练—完整解析

入口为“任务与生成”中的“小节应用与训练闭环”。本地使用已固定知识版本和已确认完整题目，不重新生成小节知识，不要求重新抄写真题。新增迁移11，只增加编制稿、历史、固定读物与请求去重表，保留已有材料和知识终稿。

## 用二元一次方程组10项知识实际运行

1. 停止旧服务、更新代码并重启 API、Worker 和前端，沿用同一个数据目录。
2. 进入任务与生成，选择自己已定稿的“二元一次方程组”知识终稿，核对选项中的“10项”和版本日期。页面优先选中名称匹配且当前有效的终稿；实际知识来自本机数据库，代码不内置一份冒充用户终稿的清单。
3. 选择2—3道代表题；每轮最多4道。只有已人工确认完整且来源当前有效的题目可选择。若仅保存了原题核对文件、尚未分题，请使用“选择核对文件，分题并确认完整题目”，在整卷研究中完成边界、选项、小问、配图条件和答案状态确认，再返回刷新本地材料。
4. 可填“重点解释怎样找到两个独立的等量关系、为什么选择某种消元方式”等研究要求，点击生成。每题起草和复核各一次，所有调用由现有单 Worker 顺序执行。符合条件的单题研究终稿会作为已审研究输入复用，不重新调用原单题研究任务。
5. 在工作稿中逐题查看分类、与本小节关系、应用映射、五阶段训练与完整解析。可以原位编辑、输入公式、增删应用映射及推理内容、保存修订。未保存修改会阻止任务切换与定稿，离开页面有保护。
6. 检查左侧10项知识的应用情况。没有被本轮题目使用的知识显示“当前选题暂无应用证据，不代表不重要”。需要更多代表题时另起一轮，不强制要求每项知识都有一道题，也不把题库分布当作课标重要程度。
7. 查看学生阅读预览；它明确标为未审定草稿，使用已保存版本。教师核查原题、引用、推理、训练提示和适用条件，明确审定后生成固定读物。
8. 下载离线 HTML。读物含知识与公式、原题配图、五阶段思考任务、逐层提示、完整解析和知识回看链接；无需联网加载数学公式资源。也可打开固定阅读版，通过浏览器打印另存 PDF。此版本尚未做专业分页出版排版，打印前检查提示与解析的展开及分页效果。
9. 继续修订会建立新的工作稿，再次审定形成新版本；旧读物的 HTML 与 JSON 保持不变。

## 应用映射的契约

每条映射包含真实原题中的逐字片段、固定知识ref、为什么想到该知识、思考操作、成立条件、路径ID和步骤序号。步骤序号从0起用于数据引用，学生阅读时转为第1步等自然编号。

系统检查：原文引用必须在题干或教师确认的图形文字条件中；知识ref必须属于所选终稿；路径与步骤存在；该知识确实在对应步骤的知识引用中；解析中使用的知识要有应用解释；训练的引用必须指向有效映射。以上是结构和来源一致性校验，不是数学证明。

题目分为主要考察、组合应用、可选路径、不匹配和依据不足。不能仅按关键词匹配，不能为了“覆盖10项”硬贴标签。未匹配／依据不足题保留判断依据，但不能同时伪装成已经完成的解析和训练，不进入学生读物的代表题部分。至少一题匹配且匹配题的缺失信息、知识缺口已处理，才可定稿。题内需要其他知识时明确列出缺口，不能杜撰终稿外知识ID。

## 五阶段训练

- 读懂条件与目标：让学生区分已知、所求及限制。
- 连接知识与关系：解释题中信息提示使用什么知识。
- 选择思路：选择或比较可行路径，说明理由。
- 独立解题：完整执行推理与计算。
- 检验与反思：检查全部条件、结论和适用边界。

每阶段含思考任务、1—3层提示、对照思考及检查要点；提示和解析在读物中折叠显示。教师需检查提示是否过早泄露答案、问题是否有效。训练围绕所选原题，不把AI改编内容冒充真题。已有思路卡的跨题迁移训练仍使用原入口，本轮没有自动完成跨全题库的题型穷举。

## 来源、调用与保存

知识使用不可变终稿；题目使用不可变完整题目版本。未核验参考答案、原始混合内容块、图片字节不会发送给模型；配图理解仍依靠教师确认的文字条件。原图保存在教师预览和学生固定读物中。模型独立研究不冒充官方解析。

复用研究终稿要求题目版本一致、来源当前有效，且其知识引用范围属于所选知识终稿；复用版本ID保留在任务与复核记录中。如果研究还使用其他知识版本，本轮不会谎称完全适用于当前小节。

每题预留5500起草＋1500复核输出 tokens，最多4题需28000输出预算和8次调用；这是输出预留，不是费用估算。失败需人工点击重试，成功调用通过检查点复用，不自动付费重发。运行中原文、知识或复用研究依据变化时，调用记录保留，但不写入过期稿件。各题成功后才形成完整工作稿，不把半成品当作全轮完成。

保存采用稿件修订和任务修订双重检查。定稿保存固定知识、题目、映射、训练、解析、复核意见、模型和来源版本，同时固定渲染后的 HTML。未经教师审定不会产生正式读物；真实中考、模拟、学期试卷等来源类别随题目保留。

## 本次验证与边界

自动测试使用10项合成方程组知识和两道明确标为“合成练习，非中考真题”的题目，以及模拟模型返回。验证生成、原文和知识引用、五阶段顺序、人工修订、显式审定、离线公式与知识回链、终稿继续修订、来源变化拒绝、失败检查点复用、已有单题研究终稿复用及HTML转义。

开发环境没有用户本机数据库、真实10项知识终稿、已核对真题或真实模型密钥。因此本次完成的是可在本机使用实际材料运行的闭环实现及合成验证，不是已经替用户完成真实试卷的数学教研审定。浏览器视觉和真实付费模型输出仍需本机验收。
