# 知识草案、定向完善与关系候选使用说明

## 更新与入口

停止旧服务，在仓库执行：

```bash
git pull --ff-only
python3 scripts/setup.py
python3 scripts/dev.py
```

进入左侧“知识与关系”。当前页面支持知识清单、正文、分类核查意见、定向完善、完整性建议、关系候选、教师审核和固定知识版本。具体新流程见 KNOWLEDGE_ACTIONS.md。

旧资料、核对记录、草稿和交付保持原样。启动增量增加知识表及迁移版本4，不需要清空或重新上传。原文件仍在本机；本轮不改已有小册子的内容。

## 第一次真实生成

1. 展开“模型服务配置”，填写OpenAI兼容的Chat Completions地址（如 https://api.openai.com/v1）、服务商的实际模型ID及API Key。保存配置不测试连接，也不调用模型；没有密钥或模型名时生成按钮不可用。
2. 默认为JSON object模式，兼容端点不支持时可关闭；关闭仍要求内容是严格JSON。输出长度参数默认自动：gpt-5/o1/o3/o4模型使用max_completion_tokens，其余用max_tokens，也可按服务商要求手动指定。并非所有兼容服务已实测。
3. 先在“内容规划”核对并定稿领域、二级主题及学习要求。不要求另行输入教材知识正文；保存规划后还需确认当前规划。
4. 在“知识与关系”选择“已确认内容规划”和“二级主题”。页面自动带入名称、范围、目标对应和来源学习要求，再点击“创建知识单元”。新建不再使用试点或手填独立主题。规划仅保存未确认时不会出现在列表；需在“内容规划”的核对与确认中定稿。重复创建会打开同规划主题和修订的已有单元，不覆盖人工内容。名称和范围在内容规划中维护，创建后可修改目标学生与补充说明并保存新修订。规划变化会使关联单元过期。原有单元与审核记录在“已有知识单元与历史批次”中保留。
5. 检查显示的服务与发送范围，勾选发送确认，点击“生成知识清单”。这是一次真实、可能计费的模型调用。当前不自动发送上传原件、试卷、图片、教材正文或其他资料。
6. Worker生成清单后暂停。选择想展开的条目，再点击“展开选中的知识草案”。默认清单最多12项，可设1至30；限制不是知识完整性的承诺。可先处理小批，未展开项不等于不重要。
7. 每4项调用一次展开，再调用一轮数学检查，提出需要教师判断的问题。页面显示阶段、每次尝试和服务商报告的用量；未报告时明确为未知，不用估算值冒充实际用量。

## DeepSeek 配置与空正文排查

官方接口填写 `https://api.deepseek.com`，模型按当前账户可用ID填写（如 `deepseek-flash`），输出长度参数用自动或 `max_tokens`，JSON模式可开启。思考模式默认“自动”：官方DeepSeek知识草案请求显式发送 `thinking.type=disabled`，其他服务不附加该厂商字段。也可选关闭或开启；开启会消耗更多输出预算，未验证其对数学准确性的改善。

DeepSeek官方文档说明思考模式默认开启： https://api-docs.deepseek.com/guides/thinking_mode/ 。知识清单原有1800输出token可能先用于思考而没有最终JSON；JSON模式也可能返回空白。因此不能只根据空正文认定密钥无效。新错误分别记录finish_reason、是否包含思考信息及服务商实际usage，不使用reasoning_content冒充知识内容。

API Key只填写纯密钥，不含中文注释、内部空格、控制符、引号或Bearer前缀。新保存时提前拒绝非法字符并且不回显密钥；旧配置中的非法密钥会以安全提示呈现，仍可在页面重新填写。服务地址也拒绝中文备注和空格。异常不再只显示Python的latin-1编码错误。

改变思考模式后保存设置，重新勾选发送范围，点击“生成知识清单”建立新批次。旧批次绑定旧配置且保留原记录，不会自动改用新配置。建议初次试跑将清单上限设为3，超时设为180秒。

## 预算与中断

默认每批最多16次尝试，输出token预留预算30000。清单预留1800，每组最多4项展开预留5000，数学检查预留2200。API在展开前检查所选数量是否有足够预算；失败及用量不明的尝试也占预留。该预算不是金额上限，也不包含输入token计费；金额以模型服务商为准。

每次调用有90秒超时（可调整10至180秒）。无重定向传递密钥，不自动重试失败调用。调用超时或Worker退出时，外部服务可能已经计费。

Worker重启会将知识任务标为中断，不自动再次计费。编辑可点击“重试未完成步骤”，复用已保存的清单、已完成批次及成功响应；未完成尝试需再次调用，仍受原任务预算限制。达到预算时提高配置后另建候选，而非无限重试。

任务固定模型、服务、输入范围及提示词版本。更换模型或地址后，旧任务不会偷偷发送给新服务；需恢复原配置或创建新候选。轮换同一服务密钥可用于后续人工重试。

## 教师校正、选择范围

生成完成不等于数学正确。条目包括概念／性质／定理／方法，及表述、条件、核心公式、正例、易错点或反例、掌握表现、方法步骤、不确定问题。

正文可直接修改，带公式的内容使用现有完整正文公式编辑器；核心公式字段为纯LaTeX，保存后显示数学预览。结构或可渲染性检查不验证数学语义。

- 可以逐条修改后“保存条目修订”，有未保存内容时禁止批量确认；错误时保留本地输入。
- 可以选择多个条目，批量保存为基础必备／连接与综合／拓展选读／不纳入，这一步不自动审核通过。
- 可以让 AI 补充／修订／拆分，也保留手工补充入口、初始草案与历史修订。
- 过滤“有疑问条目”集中核查。AI检查可能出错；有AI意见的纳入条目，需填写教师处理说明。数学正确性或未分类的未解决问题仍需修正并清空；范围、组织、教学问题可以先分类并记录依据，再由教师确认。系统信息不作为数学错误阻断审核。
- 拒绝内容可填写批量退回原因及审核人，点击“退回选中项”；不会删除原草案。
- 确认时填写审核人并勾选声明，只确认选中条目。未确定范围、必需内容缺失或公式非法的纳入条目不能确认。不纳入只记录范围决定，不被判成数学错误。
- 改动已确认条目的内容、范围或说明，会撤销该条目的确认。审核本身也绑定修订号，拒绝旧页面覆盖新内容。

“沿用清单生成新候选”复用知识ID，重新起草选中知识，不覆盖旧批次或教师修订。新范围请重新生成清单。已支持当前批次的定向候选采纳和知识关系；跨批次同义整合与全册图谱尚未实现，不凭名称自动合并不同知识。

## 固定知识版本

点击“固定已审核知识版本”，只冻结已确认条目及不纳入决定，保留范围、审核人、模型和输入快照。至少有一个已确认且纳入的条目才允许固定。未审核条目不会进入文件；版本包含已审核数与选中数，不暗示单元完整。

可以下载审核版JSON，后续修改、重生成、单元变更不会改变旧JSON。官方课标覆盖字段始终为false，表示尚未做该项核验，不代表内容不适合初中。

知识版本与原有小册子交付是两个对象，本阶段不自动送入解题或发布。下一阶段才接入自动关系与题目研究。

## 密钥与本地文件

配置位于本机数据目录的knowledge-provider.json，权限设为仅所有者读写（Windows实际权限依赖账户ACL），不是加密存储。API不返回密钥，日志、模型输入、原始任务记录不包含认证头。data目录已被Git忽略，备份时仍需妥善保管配置。

也可通过MATHLET_MODEL_BASE_URL、MATHLET_MODEL_NAME、MATHLET_MODEL_API_KEY设置初始默认值；页面保存后的配置优先，明确清除密钥后不再回退到环境变量。API和Worker使用相同环境与数据目录。

## 实测边界

自动化使用模型测试替身及模拟HTTP传输，覆盖请求格式和失败流程，不冒充真实服务连通或数学质量验收。本轮环境未配置真实模型密钥。用户配置后的具体模型输出、内容范围、费用及本机浏览器体验仍需实测。

## 清单与展开结果的身份差异

展开按服务器分配的知识 ID 对应清单，而不是按名称字符串匹配。模型改写名称或合法类型时，候选保留清单名称与类型，原模型正文完整保存在 original_body 和调用记录中；差异列入“需要核查”的意见。教师必须核对正文是否仍对应该知识，必要时修改名称、类型和正文，并填写处理说明后才能批准纳入。生成完成不代表数学内容已验证。缺失、重复、未知 ID 以及不符合正文结构的输出仍拒绝，整组不部分写入。

旧任务仅因“展开结果改变了清单的名称或类型，请重试”失败，且已保存完整响应时，用户主动重试会先按新规则重新校验。通过则调用记录标为 revalidated（历史响应重校验，无新增调用），保留原错误说明与用量，不为该步骤再次调用模型。仍未完成的后续步骤可能产生调用费用。已成功组和教师修改不覆盖；范围变化仍拒绝重试旧任务。

## 知识公式阅读

知识正文默认以连续阅读方式显示，核心公式、正文公式和初始草案直接渲染为MathML。正文支持明确的 `\(…\)`、`\[…\]`、`$…$`、`$$…$$` 定界；无标记的普通文本不猜测转换。已有保存的MathML优先使用，缺少时调用本地公式预览接口，不调用大模型。

点击“编辑知识内容”后修改正文；核心公式可使用可视化编辑器，LaTeX源码默认收起。未保存的公式也会更新预览；渲染失败保留源码并提示核查。返回阅读不丢弃未保存编辑，仍需保存条目修订。此功能只改变显示，不修改知识数据、审核状态或已固定版本。

## 常见模型公式命令

本地公式转换支持 `\odot O`（圆的记号）及 `\mathbb{R}` 等数集字母。此前的“不支持”源于本地命令白名单，而非判断数学内容错误。更新并重启 API 后，现有内容重新打开即可渲染，无需模型重生成。命令仍经过白名单、结构和MathML输出检查，不允许链接、HTML或自定义宏。渲染成功不等于表述正确，也不意味着知识属于初中课标范围。
