# 开发阶段与验收

## 阶段 A 本地基础工作流

本轮实现：真实 DOCX/PDF 上传、原始资料留存、结构提取与 PDF 原页图、人工核对、编辑提纲、正文修改、修订批注、明确批准、来源变更使批准失效、离线 HTML 不可变快照。加入本地运行脚本、测试与 GitHub Actions。

验收：用本机实际资料完成上传到下载，停止重启后数据仍在；未审核不能交付；编辑后旧批准失效；过时请求返回409；旧交付文件在后续修改后保持不变。实际试卷只在本地验收，不提交公共仓库。

剩余基础改进：自动/人工分题、跨资料来源选择、复杂公式编辑、资料类别修改、原题图上的定位、完整正文历史与差异、批注解决状态、解析进程隔离、跨平台依赖验收与数据库迁移。

## 阶段 B 模型与研究流水线

0.2 内容规划已增加AI读取导入资料、构建来源绑定的领域与二级主题、学习要求对应建议、编辑定稿和按主题进入知识生成；保留传统教材目录功能：教材目录规则识别、树调整、单元与跨章关联、人工课标摘录及对应、结构确认、与编辑提纲衔接。操作说明见 CONTENT_PLANNING.md。全册课标覆盖的自动审查和知识身份自动归并仍未实现；多版本关联与单题模型研究已接入，见下方阶段2／3。

引入可配置模型适配器、明确的资料发送边界、结构化研究产物与来源引用、任务检查点、局部重试、调用预算与输出版本绑定。先完成单题研究、独立核验和教师修订，再扩展为单元生成。

验收：真实调用有记录；无 Key 时明确不可运行；模型失败不显示成功；修改来源后旧任务结果只成为过期候选；不同解法允许并存，不以标签强制唯一思路。

## 阶段 C 完整单元与出版

课标覆盖表、基础概念与性质库、真题知识连接、逐步撤除提示的训练、专业公式排版、分页 PDF、结构化编辑与版本差异。

验收：教师按来源核对知识，学生能独立建立关系；PDF与网页来自同一内容版本；打印无漏公式、图形遮挡和答案错配。

## 阶段 D 视觉和视频

先实现精确函数/几何模板，再生成题目所需的参数演示。讲解脚本审核后生成旁白、字幕和视频；纸面保留完整核心解释。二维码采用稳定地址并与旧读物版本匹配。

## 阶段 E 正式交付与维护

人工发布、访问控制、资源使用记录、勘误入口、已发布版本修订策略、备份恢复与地方适配。互联网发布前新增身份与权限、多用户一致性以及部署方案；不能直接开放当前本地 API。
