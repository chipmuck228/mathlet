# 原题中的数据表

## 教师流程

在“原题核对”打开整题编辑，数据表显示为行列网格。点击单元格，在网格下方编辑文字或使用既有公式编辑器插入公式。可添加/移除表格、增删行列、调整表头行数；空白存为空字符串，不自动补零。修改后点击“保存整份修改”，核对后整卷定稿。

已有提取稿不需要重新提取整卷。可基于终稿继续修订，在目标题点击“AI整理本题表格”，阅读建议后“采用表格建议并编辑”；也可以手工添加数据表。AI只整理有依据的行列，不解题补数。采用不会自动保存或定稿，继续核对表头、数字、空格和题干是否重复。

## 自动处理范围

DOCX顶层原生表格可读取行列和单元格中的OMML公式。为避免把整页版式误当数据表，只自动处理2×2以上、短单元格且符合容量限制的表格。合并表头按矩形网格展开并重复对应文字，保留提取说明，教师需核对表头归属。复杂、嵌套或超大表格保留原始文字，不丢弃来源。清晰连续的制表符行列可自动整理；不会凭空白宽度猜测PDF列对应。

AI整理使用当前题干、已有表格、本题原文块和可读取的DOCX原生结构；本版没有发送PDF原页或扫描图像像素。扫描表格应对照原件手工转录，不能把“整理建议”理解为视觉识别保证。

## 数据与下游

每题`tables`包含`key`、`caption`、`header_rows`、二维字符串`rows`及来源参考。单元格公式沿用`\(LaTeX\)`，数字保持字符串，包括前导零与空格。每题最多10表，每表60行20列；每格最多2000字符，整表最多60000字符。

结构随不可变整卷JSON进入题目版本、题库、研究模型输入与小册子HTML。模型提示强调行列关系及空白不等于0；表格数据参与重复检测与证据匹配。表格单独修改也会产生新修订并撤销当前题目确认，旧版本及旧交付不被改写。来源定位保留为参考，不输出到学生表格中。新旧稿导入时表格来源随原文块映射。

阅读版生成真实HTML表格，单元格公式通过既有数学渲染链输出；浏览器打印PDF使用表格样式及可重复表头。宽表可横向查看，建议交付前检查纸张方向。没有承诺所有宽表均能自动适配任意纸张。

## 验证范围

使用合成DOCX、模拟模型响应验证原生分数、空格和前导零、整卷保存/定稿、后续研究与题库、表格变更撤销确认、旧文件不可变、来源指纹稳定、结构限制、安全HTML与公式、AI显式采用及过期保护。未调用付费模型，未使用用户真题，未进行真实扫描PDF识别或打印视觉验收。
