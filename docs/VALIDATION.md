# Mathlet 验证记录

## 自动转换字体配置继承

2026年11月10日，针对手动导出正常而自动转换缺中文的反馈，修正自动转换不继承日常字体配置的差异。选择性复制字体与语言设置及配置目录字体，保持独立临时配置；不复制宏或最近文档，不改源配置。26项后端测试、13项前端测试及构建通过，新增覆盖设置筛选、原配置不变、配置路径覆盖和无配置提示。Linux 上使用已安装 Noto CJK 字体实测合成中文DOCX，含分式及中文表格，转换PDF可提取中文并渲染检查。此证据不复现用户的macOS问题，不保证继承配置就能解决所有缺字；macOS实际试卷仍需重新生成验收。

## 原文预览重新生成

2026年11月10日，DOCX 原页增加重新生成入口。已有 PDF 时也会实际执行转换；重复请求去重，原 PDF 保留到新文件通过检查后原子替换。生成中与失败时仍可查看旧版，成功后按文件版本刷新 iframe 并禁止缓存 PDF。23项后端测试、13项前端测试及生产构建通过；回归覆盖重新入队、版本变化、失败保留旧PDF与源内容不变。真实浏览器与中文字体效果尚需本机验收。

## 提取结果与原文双栏核对

2026年11月10日，左侧统一为提取正文及配图的修订视图，右侧移除提取HTML，改用原始PDF／LibreOffice从DOCX独立转换的页面。新增初始正文的增量字段，旧资料不推断初始值。预览任务独立失败、重试去重，不修改来源或已交付内容。23项后端测试、11项前端组件测试与生产构建通过。实测合成DOCX的上标公式和表格经本机soffice转换成功，并渲染检查PDF页面；用户真实文件和macOS/Windows转换未验收。浏览器视觉验收尝试被当前环境的 Chromium socket 权限限制阻止，未宣称已完成。

块与DOCX页码未自动建立映射，按题号手动对照；PDF原件字节保持一致。转换版受字体与LibreOffice排版差异影响，不能视为与Word完全一致。

## 完整正文公式编辑更新

2026年11月9日，插入公式入口改为带入当前块完整正文，保留全部文字、公式边界与选项；不再默认打开空白公式框。主阅读区改为连续显示。新增整块编辑、局部公式修改、应用及取消测试；9项前端测试、20项后端测试及生产构建通过。真实浏览器视觉与数学键盘仍待本机验收。

## 公式插入位置更新

2026年11月9日，修正输入文字后丢失插入位置的问题；选中片段原样带入公式编辑器，只替换选区；空选区新增公式保持空白。LaTeX 输入中的模板保留前后内容。11项前端组件测试、20项后端测试和生产构建通过。新增测试覆盖光标插入、输入后插入、外部候选替换后丢弃旧选区，以及公式模板局部插入。组件测试使用 MathLive 测试替身，真实数学键盘仍需本机验收。

## 公式核对与编辑更新

2026年11月9日，结构化原生公式提取、MathLive可视化编辑、LaTeX输入、旧资料候选及离线MathML输出加入工作台。前端生产构建通过，20项后端测试和6项前端组件测试通过。

回归用例包含用户举出的平方与分式四个选项，验证原生上标与分子分母不再压平、公式修改后的保存重开与离线导出、非法命令和不完整公式不能确认、候选生成不覆盖人工修订、旧库升级不猜测x2及旧交付格式兼容。前端验证仅替换目标公式或选中文字，其余条件与分式保留；公式编辑器在该组件测试中被替换为测试实现，不代表真实数学键盘已验收。

用户实际试卷提取仍为54块、727处原生公式。其中695处转换为支持的可编辑表达式，32处不支持的结构显示人工处理占位；转换成功只说明格式通过支持范围检查，不表示数学含义已经教师核对。用户原件不进入仓库。

编辑器通过动态导入加载，字体与许可证复制到本地静态资源，不使用CDN。离线导出采用MathML，不依赖在线公式脚本。构建对MathLive延迟加载包给出大于500KB提示，不影响构建；不把包体提示隐藏为已优化。

真实浏览器的MathLive布局、数学键盘、手机操作与打印版式仍未完成验收。PDF／图片公式OCR、复杂Office Math全覆盖、Word原页渲染与数学语义证明未实现。

## 连续核对更新

2026年11月9日，原题核对改为左侧连续编辑、右侧连续证据对照。前端构建通过，15项后端测试及3项 Vitest/Testing Library 前端组件交互测试通过。

新增后端测试验证选中范围以外状态不变、保存修改不自动确认、最后一项版本冲突时整批回滚、拒绝重复与跨资料ID、多块同时影响同一草稿仅失效一次、原交付快照不变。前端组件测试验证全部正文同时存在、查找不隐藏上下文、仅提交实际修改、仅确认选中内容、冲突后保留输入。

前端测试在 jsdom 中运行，不是浏览器视觉或真实滚动验收。DOCX 仍为提取预览与配图，不是 Word 原页。公式与表格富文本编辑未实现；现有资料、来源ID和数据表结构保持兼容，无需重建数据库。

## 0.2 内容规划

2026年11月9日，新增规划测试后，全部12项后端测试通过，TypeScript与Vite构建通过。新增覆盖树层级、重复号保留、无虚假课标覆盖、循环拒绝、来源绑定、课标引用校验、确认与过期修订、提纲创建幂等、源变更撤销批准、增量迁移保留数据，以及普通试卷不被误判为目录。

使用实际目录 DOCX 验证：识别6个册次和239个链接条目，共245个节点；保留239个原链接；重复的第二十六至二十九章分别提示。未录入课标时要求列表保持为空。测试数据和用户文件不提交仓库。

回归测试还验证：结构确认后，仅核对关联目录原文而不修改文字，仍可创建提纲；原文修改才使规划过期，避免“先确认规划、再核对来源”产生无法继续的流程。

0.2 尚未完成浏览器视觉验收、macOS/Windows本机运行、真实模型调用或全册课标核验。之前的本地浏览器端口访问限制仍未解决。单元提纲为模板，不是 AI 解答。
