# Agent 协作与人工审核

本文件是后续阶段的实现约定。0.1 的 Worker 仅解析真实资料，提纲创建由确定性模板完成；尚未调用模型，不把模板当 Agent 研究成果。

## 职责和输入输出

| 角色 | 输入 | 输出 | 不允许的行为 |
| --- | --- | --- | --- |
| 资料整理 | 原件、提取块、来源属性 | 题目候选、图表关联、疑问位置 | 根据图形观感补条件 |
| 知识研究 | 已确认课标和知识来源 | 定义、性质、成立条件、引用 | 只从题库频率推断全册范围 |
| 解题与连接 | 已确认题目、知识依据 | 可行解法、共同对象、连接依据、边界 | 宣称唯一或最优解却无依据 |
| 独立校验 | 原题和候选稿 | 独立求解、反例、错误与待确认 | 以模型一致代替证明 |
| 教学编辑 | 审核后的知识和分析 | 概念讲解、思考过程、迁移训练、答案 | 覆盖教师修订并保留旧批准 |
| 视觉制作 | 已确认几何关系与参数 | 精确图形、关键状态、演示脚本 | 从动画观测直接宣称证明 |
| 出版编排 | 批准内容和资源版本 | PDF、网页、二维码映射 | 未经人工批准公开发布 |

## 执行约定

每个任务保存输入内容及其修订、模型与提示词版本、输出结构、来源编号、待确认问题、执行状态、错误和调用用量。角色是任务类型，不要求每个角色对应一个长期服务。开始阶段可以由同一 Worker 顺序执行不同角色。

资料中的文字属于数据，不能覆盖系统指令、读取密钥、运行代码或改变发布规则。发送外部模型前明确显示接收服务与资料范围，提供人工触发；当前版无自动对外传输。

研究输出应以结构化模式返回：claims（主张及条件）、source_refs（来源及位置）、relations（连接与依据）、paths（可行推理路径）、checks（已做与未做核验）、uncertainties（未解决问题）。结构校验通过只说明格式正确，不说明数学正确。

每阶段独立保存产物，源修订变化后拒绝把过时结果覆盖到当前稿；允许保留为候选供人工比较。重新运行应创建候选修订，不覆盖已批准版本。模型失败可重试，但不能重复创建发布或重复计入已完成成果。

## 人工节点

原题核对、知识与数学审核、最终排版审核分别记录。未确认关键条件不进入正式数学分析；可先分析其他已确认题目。教师审核和程序核验互补，两者均可能出错，应保留勘误和独立复核。

## 演示与真实执行

未来可提供 sample 模式，但必须在界面、任务和导出元数据中标记。真实模型运行才显示服务商、模型和调用记录；不能用计时器或预设文字充当真实执行日志。0.1 不含先前网站原型中的流程回放。
