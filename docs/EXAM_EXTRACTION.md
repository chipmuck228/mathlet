# 原题核对：整份试卷提取、审阅与定稿

真题、模拟题、学期试卷及未分类资料的“原题核对”主入口改为整题审核。无需先逐个内容块点击“已核对”。课标和教材资料保留原有文本核对功能，旧逐块核对记录及下载接口保持兼容，不迁移成虚假的整卷批准。

## 使用流程

1. 在资料包上传 DOCX/PDF，等待完成读取。进入原题核对，保留顶部原始文件选择。
2. 点击“AI提取整份试卷”。模型只定位原文标题、完整大题、选项、小问、题图及已有解答的对应位置；随后工作台从原文精确取出文字，保留公式及原字，不重写或求解。原文没有解答时保持空缺。该任务使用现有单 Worker、模型配置、调用记录与检查点，预留10000输出 tokens。
3. 左侧默认按完整题目连续阅读，右侧为独立的原文只读预览；可下载原件、打开原页或重新生成 DOCX 预览。点击“编辑整份提取稿”可修改试卷标题、题号、题干（含选项及小问）、原文解答与核对说明，支持现有公式编辑器。可以补充漏题、移除误提题和上移整题。
4. 题图和解答图分别提供“从全部图片选择／替换”。图库包含本份原文的全部已提取图片，不局限于原先内容块；取消旧图、勾选新图即可替换，也可多选。不会修改原始图片文件。缺失图片可以取消选择，不能当成可用图片重新选入。
5. “保存整份修改”保存当前工作稿。每次修订保留历史，不对每个块或每道题设置单独的核对批准按钮。
6. 检查完标题、题目完整性、原文解答与图题对应后，勾选整卷核对声明，点击“定稿并生成原题提取文件”。这里只确认转录忠实，不表示数学解答已经证明正确，不以公式命令渲染能力否决教师的转录判断。
7. 终稿只读，可重复打开、下载 JSON。记录名以首次创建日期时间固定；正式文件加 V1、V2 等版本号，缓存到本机 data/exam-extractions，数据库同时保留权威快照。文件副本写入失败时仍可下载数据库中的终稿，不显示成整个审定失败。
8. 从当前终稿继续修订会保留记录名称并形成后续版本；从历史版本另起修改稿会新建记录，原稿及旧终稿都保留。每个终稿的文字和选定图片字节都固定，原图之后改变不会改变下载的旧文件或其只读图片。

## 与后续研究衔接

定稿时直接建立后续可选完整题目，不再要求回到逐块核对或再分一次题。原文解答只标为“未核验数学内容”，不会作为已验证答案发送给解题模型。没有题图，或已经给出必要图形文字条件的题，可直接用于题目与研究、任务与生成。

图形题的提取文件仍可定稿；文字模型研究若需要图形信息，须补充必要图形文字条件。这个条件可在整题编辑中提前写，也可后续在完整题目研究中补充，不拿它阻断原题提取定稿。单题研究容量超限时，提取文件保留全部题目和解答，明确标为需整理后研究，不静默截断后当作完整题目。

“整卷研究”的文件选择器同时列出新的整题核对终稿。选中后建立整卷记录，直接进入知识推荐和批量研究，无需重新分题。后续使用的是人工修订后的题目／解答文字，原文块只承担来源定位。

同一份原文的新终稿会成为当前提取版本。按题号或稳定题目标识尽量复用已存在题目；内容实际改变时撤销受影响的旧完整题目确认，移除的题目也撤销确认。完全相同的题目不无故创建新确认版本。旧的提取文件、研究文件与已交付读物保持不变。

## 本地文件打开

“打开本地原题提取文件”接受工作台生成的整题 JSON：若与数据库已有终稿完全一致，直接只读打开该版本；外部改过的内容或跨工作区导入作为新的待核对草稿，不能靠文件中的批准标志伪造本机教师确认。文件需匹配所选原文的哈希，图像按原文件中的名称和哈希重新关联。旧的逐块核对 JSON 使用历史兼容入口，不混成整题终稿。

## 保留的证据与限制

- 提取文件主要内容为标题、题目、原文解答及题图／解答图，附带定位、原件哈希、选定图片字节、来源类别、版本和人工核对声明，供后续 Agent 使用。
- AI 初稿和人工修订分别保留。原生内容块不会因整卷审定而被全部标成“逐块已审核”，也不会被 AI 输出覆盖。
- 模型没有接收图片像素，因此图片归属是建议，需教师对照；不根据图片名称猜条件。PDF整页图不等于已经识别出其中的每幅题图。
- 本轮未新增扫描件OCR或图像公式识别；没有可读正文时明确提示，不能从空正文编造试题。复杂公式仍可能需要人工使用公式编辑器校正。
- 单次至多500个原文块、100000字符、60道大题；选定图片合计至多32MB，本地提取JSON打开上限50MB。超限明确提示，不静默截断原题。
- 定稿的结构检查仅针对标题／题目非空、文件归属、图片是否存在与版本冲突，不判断数学答案对错。图像或原文在提取／定稿期间变化会拒绝写入过期结果。

## 本次验证

新增迁移12，采用附加表保留已有数据库。测试使用合成 DOCX、合成图片和模拟模型结果，覆盖零逐块确认即启动、公式原字保留、整题修改、全部图片替换、只读定稿和图片快照、版本继续修订、旧下载不变、本地文件打开、研究题目发布及整卷直接读取、超大解答不截断、来源变化拒绝和重复任务复用。未使用用户本机真题或真实付费模型，浏览器视觉及真实试卷完整性仍需本机验收。

## 单题标题过长的历史错误恢复

整题定位不需要单题标题；exam-v2只要求整卷标题，各题按题号与原文范围组织。旧响应若把长题干填入questions.N.title，兼容处理会忽略这个未使用的元数据字段，完整题干和原文解答仍从原始范围取出，不截断正文。原始模型返回保留用于追溯；来源、图片及其他结构校验保持不变。

更新并重启后，在原失败记录点击“重试未完成的提取”。对于保存了完整原始JSON、错误属于ExamPlan单题标题长度限制的响应，会先按新结构重新校验并复用，不新增付费调用，且恢复先于调用预算检查。如果响应还含其他不能恢复的问题，仍会报错或按既有显式重试流程调用模型；原文已变化时不能按旧依据恢复。
