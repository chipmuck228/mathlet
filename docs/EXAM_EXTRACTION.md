# 原题核对：仅题目提取与整卷定稿

当前流程：选择原文 → AI 整理标题、完整题目与题图 → 每题编辑／浏览 → 保存整份修改 → 整卷定稿 → 下载只读提取文件。

- 新提取不整理参考答案或解答图。模型按原文范围定位题干、选项和小问，后台精确取字，教师核查完整性及图题对应。
- 每题独立点击“编辑”修改题号、题目正文及配图；点击“浏览”保留当前未保存修改。试卷标题单独编辑。最终仍需“保存整份修改”或整卷定稿。
- 不展示原文定位、补充说明和整卷核对说明编辑区。原文保持只读并可下载；原文定位作为后台追溯信息保留。
- 题图可从原文全部已提取图片中选择、替换；支持公式编辑、补漏题、移除误提题及调整顺序。
- 新终稿标记 questions_only，题目数据不导出答案字段；后续研究按无参考答案处理。文件中的原始来源证据可能仍包含原文答案段落，不作为已核对答案使用。
- 旧提取稿、旧终稿及其答案数据保留；打开旧稿不显示答案编辑区，保存题目修改不会清除旧答案。旧终稿下载不变，继续修订形成新版本。
- 题目提取定稿仅确认转录，不替代数学研究。来源／图片变化及修订冲突仍阻止写入过期结果；人工审核不受公式显示警告阻断。

验证采用合成 DOCX、图片和模拟模型响应，覆盖题目模式、旧格式兼容、图片替换、独立编辑、整卷保存、定稿／导入／研究衔接及旧文件不变。未新增 OCR 或图像理解，真实真题完整性需在本机核对。

## 每题 AI 修正公式

1. 在可编辑提取稿中点击该题的“AI 修正公式”。使用已保存模型配置和当前题目（含尚未保存的修改），只发送关联原文块及对应DOCX节点的结构化公式证据。新补充题目须先保存。
2. 后台单 Worker 生成建议；正文保持不变。展开查看修正前、修正后的完整题目、每处原字／替换片段、理由、依据和未确定问题。
3. 点击“采用修正并编辑”才将建议带入该题编辑区；继续人工修改，再“保存整份修改”并定稿。也可直接“放弃建议”。

修正任务只处理公式转录，不求解或改题。仅在原文证据足够时恢复平方、分式等，不能把x2、1x一律猜成平方或分式。AI依据仍可能有误，需对照右侧原文。DOCX会重读原生公式，PDF及图片本轮不提供视觉输入，缺失结构保留并提示人工核对。

每次任务预留5000输出tokens，使用既有模型预算、调用记录与JSON解析。重复点击复用正在运行的相同任务；失败可新建任务，不自动重复收费调用。“关闭建议”不会取消已发出的后台任务；离开页面不会自动采用。题稿修订、来源改变或定稿后，旧建议失效；当前题目文字改变也不能采用旧建议。已有终稿先继续修订，旧交付不变。

测试使用模拟模型与合成OMML，不代表已在真实真题或付费模型上验收。

## 保存与定稿状态修复

保存、载入稿件统一规范化顶层字段，未保存判断对两侧使用相同字段顺序，避免后端content_mode序列化顺序及旧稿默认值导致“已保存仍不能确认”。移除题目后保存成功即可重新勾选整卷确认；不要求题号连续或与初始提取数量一致，至少保留一题。前端回归覆盖新版与旧版稿件移除多题、真实形状保存返回及修订号定稿。

## 整卷自动分批与文件名

不再因正文超过500块或10万字拒绝提取，也不要求教师手动拆卷。系统跳过纯空白无图块，将全部正文按每批约24000字、最多180块顺序处理；超长单块分片并映射回原文精确位置。前一题上下文辅助识别跨批续题，只有模型明确标识续题且题号一致时合并；答案区允许返回零题。跨片连续范围自动接合，不在同一公式中插入换行。所有批次完成后才写入可审核的整卷稿件。

任务根据实际批数准备调用次数与输出预算，每批预留10000输出tokens，不修改全局模型配置；实际费用由服务用量决定。界面显示总批数及已完成数。失败或中断可人工重试，复用已完成批次，补足剩余批次预算，不自动重复收费调用。来源变化仍拒绝过期写入。

定稿后在结果区直接显示“定稿文件名：日期时间-V版本.json”，与实际下载文件一致。只读打开其他固定版本时同步显示该版本文件名。

新增合成测试覆盖超过原500块和10万字阈值、跨批续题、单块切片／重复锚点精确还原、失败重试复用及定稿文件名。真实模型的分题完整性仍由教师核对。

## 题目起止定位修正

模型给出的结束锚点可能位于起点之前，或实际属于下一段。现在不再因单题定位错误立即丢弃整卷：

- 错选了起点之前的结束文字，且起点之后只有一个同样的结束锚点时，自动换算到该位置；有多个可能位置时不猜。
- 仍有定位问题时，仅针对当前批次进行一次AI定位复查，携带具体题号、错误与原提取建议；只接受相同数量／顺序／题号的定位修正。
- 复查仍不能定位时，该题保留为空白可编辑条目，明确标注“提取待核对”；其他正确题目正常显示。教师对照原文补全或移除空题后才能定稿，不用整块正文或答案区冒充完整题目。
- 网络／模型配置错误仍显示任务失败并允许人工重试。重试复用已完成的提取及定位复查，不自动循环收费调用。此前因为定位错误保存的原始响应可重新校验后用于复查。

每批预算包含提取10000及必要时定位复查6000输出tokens；仅有问题的批次触发复查，进度按实际完成批次统计。来源变化拒绝写入过期稿件。测试覆盖重复锚点、跨段题目、复查成功／不确定、补全后定稿、重试复用及来源变化；未使用真实模型或用户原卷验收。
