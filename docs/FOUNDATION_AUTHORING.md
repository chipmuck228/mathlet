# 基础知识编制：只审定准确知识正文

工作台“知识与关系”更名为“基础知识编制”。职责是从已确认主题生成知识清单，教师选择、阅读与修订后，整体固定准确的定义、概念、术语、性质、公式、方法、成立条件、正例及反例。

## 取消分层前置条件

页面移除“适用范围”和批量“基础／综合／拓展”选择。条目默认纳入，可移出与恢复。pending条目也可整体定稿并用于后续题目映射，系统不把它们改成core，也不将“未分层”当成“知识未审核”。

数据库旧scope字段及既有分类仍保留，以保证历史快照真实不变。新页面保存正文不需要提交scope，API省略时保留原值。历史excluded条目仍不纳入，点击恢复纳入后变为pending而不是伪造基础必备定位。

“适用范围”教学标签与“成立条件”不同：分母不为零、等式变形的等价性等数学限制仍必须完整。表述、成立条件、正反例等必填结构、公式语法、版本冲突和来源失效的检查继续保留。教师选择不等于官方课标覆盖核验。

## 取消独立关系编制步骤

不再显示知识关系标签、生成关系按钮或“先审关系才可定稿”的步骤。知识正文核对后直接整体确认，不产生额外模型调用。以前仅有知识正文的终稿视为完整知识终稿，不再提示关系待补全。

已有固定关系、历史AI候选在折叠的“历史知识关系（仅供参考）”中只读保留。基于含已审定关系的旧终稿修订时，旧关系带source_version及reference_only标记进入historical_relations，不因新正文获批而自动成为重新审定的关系。旧终稿JSON不被改写。

原有关系API保留供历史记录与已有客户端使用；当前页面不再调用。明确提交关系的旧接口仍严格检查上下文和端点，不能把来源失效或引用错误当成功。

## 在复习单元中组织连接

复习单元编制现有的“编排训练”调用同时可以生成knowledge_connections，不增加一个必经调用或独立批准环节：

- 每条连接绑定当前知识目录中的两个不同ref。
- 类型可为前置、推导、使用、对照、表示转化。
- 给出理由、成立条件和具体例子，不强行补满，可为空。
- AI复核会检查新增连接，教师在复习单元的“知识连接”栏目直接编辑，随整份单元整体审定。
- 学生读物在“连接与思路”部分呈现这些连接，可回链基础知识。

没有连接不阻断知识终稿或复习单元定稿。缺少相关研究时仍按原规则说明训练证据不足，不伪造跨题思路。历史关系只给模型参考，不自动复制为当前成立结论。数学推理与知识使用仍须由教师判断。

## 版本与验证

无新依赖和数据库迁移。知识终稿仍保持不可变，修订创建新工作稿；对话与模型建议不能覆盖教师正文。测试覆盖未分层直接定稿、无关系直接定稿、正文编辑省略scope、历史关系参考传递、旧文件不变、失效来源与版本冲突，以及同一编排调用生成并整体审核知识连接。

## 主题目标覆盖

从已确认主题规格创建知识单元后，生成清单和正文会使用目标、必含内容和基础边界；正文完成后自动检查内容安排。在同页覆盖表阅读关联知识与具体字段、缺口和处理建议。可以直接编辑判断，无需AI；也可把具体缺口带入右侧讨论，点击发送后选择补充候选或手动修订。覆盖判断不另设审批，不因AI疑问或缺口阻断定稿；数学正文及来源版本检查保持。修改正文或纳入条目后旧结果标为待重新检查，重新检查不改正文。形成终稿时一并固定覆盖记录，旧终稿不变。详见 TOPIC_PLANNING.md。
