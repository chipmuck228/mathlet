# 原题连续核对

原题核对不再通过顶部内容块按钮逐块切换。选择一份资料后，左侧按原顺序连续显示全部可编辑文本和保留的图像；右侧按相同来源顺序显示只读证据。底层来源块、ID、图片与修订号保持不变，后续内容规划和提纲引用仍可追溯。

## 阅读与修改

- 左侧可直接修改文字，输入区自动随内容增高；不需要打开每个块的独立编辑页。
- 聚焦左侧内容会将右侧定位到相应证据；右侧也可以反向定位左侧。两个阅读区域可独立滚动，小屏幕上下排列。
- 查找只定位下一处匹配，不隐藏正文，因此阅读顺序与上下文保持完整。
- DOCX 右侧仍是最初提取结果、基础公式结构和配图，不是 Word 原页渲染。PDF 右侧是已渲染的页面图。可以下载原文件进一步核对。
- 公式更新后，文字与公式混合编辑：点击公式打开 MathLive 编辑框，或选中文字插入公式。新上传 DOCX 保留常见原生公式，已有资料通过候选恢复。表格结构编辑、图形重绘、分题和来源块合并仍未实现。详见 FORMULA_REVIEW.md。

## 两种保存

“保存修改”只提交有文字变化的块，将这些块标记为待核对，不自动确认整份资料。此前已确认但被修改的内容，需要重新核对。

“保存并确认选中内容”提交当前选择范围内的文字并确认这些块。可以通过起点、终点一次选择连续范围，也可以用每段前的复选框调整选择。默认不选中任何块。界面显示所选数量与起止位置，范围可以非连续；未选中的块不会被确认。范围外尚未保存的文字保持在本页，需另行保存。

每次请求最多500块。若资料更长，分范围确认。仅保存不改变的块不会自动重写其他内容，原始证据始终只读。确认状态记录人的判断，不表示程序校验了数学正确性。

## 冲突与后续影响

新增范围保存接口一次校验全部条目的修订和资料归属，全部通过后才写入。有任意一个条目版本冲突，整次保存回滚；界面保留当前输入，提示先复制修改再重新载入。离开有未保存内容的页面或关闭窗口时有提示。

源内容改变仍会撤销关联规划确认、草稿批准；同一批中多个来源影响同一草稿时只递增一次草稿修订。旧交付快照不变。单纯确认未改动的目录内容不会使结构规划过期，继续遵循现有内容规划规则。
