# 工作台菜单与资料管理

## 当前菜单

| 一级菜单 | 二级菜单 | 职责与下一步 |
|---|---|---|
| 资料整理 | 资料包 | 必选类别后上传；查看提取状态与失败原因，重试或删除原文件。按资料类别进入核对。 |
| 资料整理 | 原题核对 | 只列中考真题、模拟题和学期试卷；提取完整题目、修订公式与配图、整卷定稿，之后进入题库研究。 |
| 资料整理 | 课标/考纲整理 | 原文提取核对，以及领域、二级主题和学习要求的规划定稿。教材/知识资料也可在这里核对来源。 |
| 内容编制 | 知识与关系 | 从已确认主题打开知识单元，生成、编辑并固定基础知识及关系。模型配置保留在此。 |
| 内容编制 | 题库研究 | 选择已定稿试卷，批量或逐题研究，题目内展开条件编辑、研究核验与定稿。支持搜索和研究状态筛选。 |
| 内容编制 | 复习单元编制 | 以知识终稿为入口扫描研究终稿，统一生成映射、跨题思路卡、分层训练；阅读、修改、整体确认、预览和下载。 |

原有内容规划并入“课标/考纲整理”的“领域与主题规划”标签。该页面只组织课标结构，确认主题后进入统一的知识与关系页面，不再嵌入第二套知识正文编辑器。

移除“题目与研究”“整卷研究”“任务与生成”“编辑与评审”“小册子预览”“交付版本”的独立菜单入口。题库研究中的知识关联、跨题思路卡和统一题库标签也不再呈现或自动加载。已审定研究可以直接下载；不再要求勾选关联／归纳，复习单元编制自动从有效终稿选择。

这些调整移除的是重复入口，没有删除历史研究、知识、提纲、训练或交付数据及其原接口。现行主流程使用复习单元的整体审核、预览和固定文件下载。文件读取的进度与重试放在资料包中，不依赖旧任务菜单。

## 类别与核对路由

新上传必须显式传入 `standard`、`textbook`、`exam`、`mock` 或 `term`。前端未选类别禁用文件选择，API缺省、unknown、空或非法类别均返回422，不创建原件。

- exam / mock / term → 原题核对。
- standard → 课标/考纲整理的原文核对标签。
- textbook → 同一来源核对入口，作为知识参考资料。
- 既有unknown资料 → 先补充类别，再核对，不再自动混入试卷流程。

`PUT /api/documents/{id}/category`允许为历史unknown记录补充类别。已有明确来源类别不原地改成其他类别，以免改变真题与模拟题等来源身份；需要时重新上传正确分类的文件。

## 原始文件删除

资料包“删除”显示具体文件名、删除范围及引用影响，确认后请求 `DELETE /api/documents/{id}`。

- 删除该资料目录中的原件、图片及原文预览；资料与任务从活动列表移除。
- 保留数据库中的来源身份、历史核对记录及不可变成果快照。这不是将已定稿文件级联清空，也不是清除所有历史文字的隐私擦除操作。
- 取消尚未执行的文件任务；正在提取或转换时返回409，等待完成后再删除，避免Worker与文件清理竞争。
- 原件和原文预览返回410，禁止重试已删除原件或覆盖其历史内容块；重复删除可安全返回成功。
- 内容规划、题目、研究、知识与复习单元的来源有效性检查识别删除状态；过期工作稿不能冒充当前有效成果。已发布HTML／JSON快照不被改写。
- 删除前将目录暂存并在数据库异常时复原。提交后清理文件，若文件系统清理失败会明确返回告警，不声称已物理删除干净。

此改动使用已有documents.status的deleted状态，不清空旧数据库，不需要新增依赖或迁移脚本。

## 验证

合成资料测试覆盖强制类别、按类别路由、菜单层级、去除重复标签且不加载其API、题目内核验与定稿、规划交接知识页面、删除确认、队列取消、读取中拒绝删除、来源失效、禁止重试已删文件及已交付文件内容不变。不操作用户本地真实资料。
